# New-HSK-Anki-Cards

This repo holds the *New HSK1-6 Anki Decks* to practice your chinese with

Decks are currently fully available in french but we are working on a system for translating them into any language.

At the moment english and italian are fully available up to HSK3
Italian and Russian are still in WIP

## Where are the Decks?

Simply go into the `decks --> [your language] --> New_HSK[1-6]` folder and download the `.apkg` file to import it directly into anki
